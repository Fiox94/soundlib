macOS · 효과음 라이브러리 관리

수십만 개의 효과음에서
그 소리를 찾아 바로 DAW로.

SoundLib은 내 컴퓨터에 있는 효과음 폴더를 색인해서 찾고, 듣고, 재고, 고른 소리를 REAPER에 바로 꽂아 넣는 데스크톱 앱입니다. 클라우드도, 계정도, 구독도 없습니다.

macOS용 받기 무엇을 하는지 보기 v1.0.0 · Apple Silicon

내 컴퓨터에서만

색인·별점·태그·메모가 전부 이 기계 안에 남습니다. 인터넷이 없어도 그대로 동작합니다.

원본은 건드리지 않음

스캔은 목록만 만듭니다. 파일을 옮기거나 다시 쓰지 않습니다 — 이름 바꾸기처럼 직접 시킨 일만 빼고요.

키보드로 전부

↑↓로 훑고, 스페이스로 듣고, 숫자로 별점을 매기고, S로 보냅니다. 손을 마우스로 옮기지 않아도 됩니다.

Find

파일 이름에 없는 단어로도 찾습니다

clang 이라는 이름의 파일은 하나도 없지만, 모루 타격·칼날 울림·검 부딪힘이 나옵니다. 영어 동의어 사전과 오타 교정, 그리고 라이브러리 안에서 스스로 배운 연관어로 검색을 넓힙니다.

  • whoosh -light — 빼고 싶은 말은 앞에 빼기
  • "metal hit" — 붙어 있는 구문만
  • 길이<2 bpm>120 채널=1 — 숫자 조건도 검색창에서
  • UCS 카테고리로 자동 분류, 탭마다 다른 검색
Similar

하나를 고르면, 비슷한 소리 순서로

모든 파일에 소리 지문을 남겨 둡니다. 하나를 고르고 비슷한 소리 찾기를 누르면 이름이 달라도, 다른 팩에 들어 있어도 소리가 가까운 순서로 줄을 세웁니다. 유사도는 퍼센트로 같이 보여줍니다.

  • “이것보다 조금 더 무거운 것” 을 이름 없이 찾기
  • 여러 팩에 흩어진 같은 계열 소리 한눈에 보기
Measure

들어서는 모르는 것을 숫자로

라이브러리를 한 번 분석해 두면 목록에서 바로 보입니다. 라우드니스로 줄을 세우고, 파일마다 무엇이 재어졌고 무엇이 추정인지 구분해서 보여줍니다.

  • EBU R128 라우드니스(LUFS) · 샘플 피크 · 클리핑 구간
  • 스테레오 상관도 — 위상이 뒤집힌 파일을 미리
  • 네 개의 성격 축: 무게 · 금속성 · 우쉬 · 날카로움
  • BWF · iXML 메타데이터 읽기와 쓰기
Layer Recipe

내가 레이어를 쌓는 방식을, 레시피로

내 REAPER 프로젝트를 읽어서 “무거운 칼 휘두르기 = 금속 우쉬 + 공기 + 울림 꼬리” 처럼 소리를 겹친 자리를 찾아냅니다. 겹 사이의 시간차와 음량차는 그대로 두고, 재료만 라이브러리의 비슷한 소리로 바꿔 변주를 만듭니다.

  • ← → 로 변주를 넘기며 바로 들어보기
  • 마음에 드는 조합을 트랙별로 REAPER에 보내기
Clean Up

여러 폴더에 흩어진 같은 파일을 정리

이름과 크기가 같은 파일은 확실한 중복으로, 소리만 비슷한 것은 따로 표시해 사람이 고르게 합니다. 별점·태그·메모를 붙여 둔 쪽을 남기고, 지우는 대신 휴지통으로 보내서 되돌릴 수 있습니다.

  • 몇 개, 얼마만큼 비워지는지 누르기 전에 보여주기
  • 켤 때 하루 한 번 자동 백업(최근 7벌) · 이름 바꾸기 되돌리기
S

S 한 번이면 DAW 편집 커서로

고른 소리를 REAPER의 편집 커서 자리에 바로 넣습니다. 파형에서 구간을 잡아 두면 그 구간만 갑니다. 끌어다 놓아도 되고, 안 되는 환경에서는 클립보드로 넘깁니다 — 조용히 실패하지 않습니다.
